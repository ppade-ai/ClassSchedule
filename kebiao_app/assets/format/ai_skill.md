# 课表导入 Skill —— 把教务课表转成「通用文件」

> **这份文件是给 AI 看的指令。** 把它连同你的教务课表（PDF / Excel / 截图 / 复制的文字）一起发给
> 任意 AI（DeepSeek、ChatGPT、Kimi、豆包…），AI 会按下面的规范输出 CSV「通用文件」，
> 再把这个 CSV 粘回课表 App 即可导入。
>
> 版本：skill v1（对应 App v0.15+、数据格式 v1）

---

## 一、你的任务

用户会给你一份**教务系统导出的课表**（可能是 PDF、Excel、图片截图，或直接粘贴的文字）。
你要把它转成**下面规定格式的 CSV**。

**输出要求（必须严格遵守）**

1. **只输出 CSV 原文**。不要解释、不要前后加说明文字。
2. **不要用 Markdown 代码块围栏**（不要 ``` ），直接给纯文本，方便用户整段复制。
3. 第一行必须是**表头行**（列名与下面完全一致，顺序可任意）。
4. 一行 = 一条「星期 × 节次」记录。同一门课在周一和周三都上，就输出**两行**。
5. 字段内如果出现**英文逗号**，用**双引号**把整个字段包起来（CSV 标准）。
6. 不确定的字段**留空**，不要编造。
7. 表格中若有需要说明的地方，用**以 `#` 开头的整行**做注释——App 会自动跳过。

---

## 二、输出格式 A：基础课表（每学期固定的课）

表头（12 列）：

```
课程名称,类型,教师,教室,星期,起始节,结束节,起始周,结束周,周类型,颜色,备注
```

| 列 | 说明 | 取值 |
|---|---|---|
| 课程名称 | 课程全名 | 非空 |
| 类型 | 课程类型符号 | `☆`讲课 / `★`实验 / `○`上机 / `●`实践（不确定就填 `☆`） |
| 教师 | 教师姓名 | 可空（与教室至少一个非空） |
| 教室 | 地点，含校区 | 可空。例：`教学楼A103` |
| 星期 | 1=周一 … 7=周日 | 1–7 |
| 起始节 | 起始节次 | 1–10 |
| 结束节 | 结束节次 | ≥ 起始节 |
| 起始周 | 生效起始周 | 1–60 |
| 结束周 | 生效结束周 | ≥ 起始周 |
| 周类型 | 单双周 | 空=每周 / `单`=仅奇数周 / `双`=仅偶数周 |
| 颜色 | 十六进制色 | `#RRGGBB`，**不确定就留空**（App 会自动配色） |
| 备注 | 备注、教学班等 | 可空 |

**示例**

```
课程名称,类型,教师,教室,星期,起始节,结束节,起始周,结束周,周类型,颜色,备注
概率论与数理统计(D),☆,张老师,教学楼A103,1,1,2,1,9,,,
数据结构与算法,☆,王老师,机房1,2,1,2,1,17,,,
大学物理(A)Ⅱ,☆,陈老师,教学楼C101,4,1,2,1,4,,,
大学物理(A)Ⅱ,☆,陈老师,教学楼C101,4,1,2,6,14,,,
```

## 三、输出格式 B：调课 / 临时课（补丁，只影响指定周）

表头（14 列）：

```
定位类型,定位值,星期,起始节,结束节,周类型,操作,课程名称,类型,教师,教室,颜色,过期日期,备注
```

| 列 | 说明 | 取值 |
|---|---|---|
| 定位类型 | 按周还是按日期 | `weekOffset`（周序号）/ `exactDate`（公历日期） |
| 定位值 | 与上一列对应 | `weekOffset` 填周号如 `3`；`exactDate` 填 `2026-09-08` |
| 星期 / 起始节 / 结束节 | 同格式 A | |
| 周类型 | 单双周 | 空 / `单` / `双` |
| 操作 | 对该格做什么 | `add` 加课 / `replace` 替换该格全部课 / `remove` 清空该格 / `modify` 只改教师教室 |
| 课程名称 | 课程名 | `remove` 时可留空 |
| 类型 / 教师 / 教室 / 颜色 / 备注 | 同格式 A | |
| 过期日期 | 过了这天不再生效 | `YYYY-MM-DD`，可空=不过期 |

**示例**

```
定位类型,定位值,星期,起始节,结束节,周类型,操作,课程名称,类型,教师,教室,颜色,过期日期,备注
exactDate,2026-09-08,2,1,2,,replace,高等数学答疑,☆,助教老师,教学楼A101,,,只此一次
weekOffset,3,1,3,4,,add,线性代数,★,孙老师,教学楼B101,,,临时加课
exactDate,2026-09-10,4,3,4,,remove,,,,,,,停课一次
```

## 四、必须遵守的转换规则（重要，教务导出常见坑）

### 1. 周次断档必须拆成多行

基础课的「起始周 / 结束周」是**连续区间**，表达不了断档。
所以看到 `1-4周,6-14周` 这种，要**拆成两行**：

```
大学物理(A)Ⅱ,☆,陈老师,教学楼C101,4,1,2,1,4,,,
大学物理(A)Ⅱ,☆,陈老师,教学楼C101,4,1,2,6,14,,,
```

### 2. 单周写法

`第4周` → 起始周 = 结束周 = `4`（不是 `4-4周`，也不是 `4-4`）。

### 3. 单双周

`1-17周(单)` 或表头标注单周/双周 → 起始周=1、结束周=17、周类型=`单`。
**不要**把单双周拆成两行，用周类型列表达即可。

### 4. 节次与课程配对

教务表里一格通常写着 `(1-2节)`。填 `起始节=1、结束节=2`。
**一格 = 一行**；同一门课出现在不同星期，就输出多行。

### 5. 教师名尾部噪声

导出文字里可能混入行号，例如 `李老师1`、`张老师2`。
**教师名不含阿拉伯数字**，把尾部数字去掉 → `李老师`、`张老师`。
（若名字本身含数字，如 `排球场5` 这类是教室而非教师，保持原样。）

### 6. 教室与校区的冗余

`校区:校本部` 与 `教3105(主)` 表达的是同一件事。
教室列统一写成 `教学楼A103` 即可（不要把括号里的校区后缀重复保留成 `教3105(主)`，**去掉 `(主)`**）。

### 7. 集中周课程（实训 / 实验）

教务表底部常有「其他课程」区，形如 `JAVA语言课程设计●杨老师(共2周)/16-17周`。
它不是固定格子的课，**建议不要放进基础课表**，而是作为**格式 B 的补丁**输出（`weekOffset` + `add`，
或按用户指定的周次）。若用户没说明，就在 CSV 末尾用 `#` 注释一行提示：

```
# 以下集中周课程未自动录入，请用户确认后自行添加：JAVA语言课程设计 16-17周
```

### 8. 颜色一律留空

教务导出没有颜色信息，**不要编造颜色**。App 会按课程名自动配色。

---

## 五、输出前的自查清单

- [ ] 第一行是表头，列名与规范**完全一致**
- [ ] 一行一条记录，同课不同天**各占一行**
- [ ] 周次断档**已拆行**
- [ ] 单双周用**周类型列**表达，没有拆行
- [ ] 星期是 **1–7 的数字**（不是「周一」「星期一」）
- [ ] 节次是数字，且 `结束节 ≥ 起始节`
- [ ] 教师名**没有尾部数字**
- [ ] 颜色列**留空**
- [ ] 没有 Markdown 代码块围栏、没有解释文字

---

## 六、用户拿到 CSV 之后怎么做

1. 把 CSV 内容**整段复制**
2. 打开课表 App →「更多」→「**编辑总入口**」→「**批量文本**」
3. 选「**通用表格**」模式 → 粘贴 → 点「**转成标准行**」
4. 检查有效行/错误行提示 → 点应用（选择**追加**或**覆盖**）

> App 会逐行校验：字段数、星期范围、节次区间、周次区间、类型符号、颜色格式都会检查，
> 错误行会标红并给出原因。所以 AI 出错也不会污染课表，最多是那一行被拒绝。
